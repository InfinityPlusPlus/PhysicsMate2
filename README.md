This is a hobby project of mine, to learn programming, android development, and physics.
And this is also a bounty of bugs.

Made in Android Studio. The .apk file can be found in app > release > app-release.apk

In the **Home** section, there are 3 tabs:
1) Physics - Contains Physics-based formulas and solve them
2) Maths -  Contains mathematical tools
3) External Links - Useful links to websites on the internet (to be added)

In the **Notes** section, the user can add, save and view formulas
(The feature to add and save isn't implemented yet. Only viewing in-built formulas can be done as of now.)

The **Settings** section will contain color theme, font size, and other stuff (to be implemented)
